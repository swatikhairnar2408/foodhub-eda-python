# FoodHub Restaurant Order Data Analysis

## Project Overview
This project focuses on an Exploratory Data Analysis (EDA) of the FoodHub platform dataset. FoodHub is a food aggregator app that stores transactional data of restaurant orders. The objective is to analyze the data, extract deep operational insights, and provide actionable business recommendations to improve customer retention and revenue.

## Core Objectives
* Clean and preprocess the restaurant order dataset using Python.
* Analyze customer behavior, popular cuisines, and peak ordering times.
* Investigate operational bottlenecks related to food preparation and delivery times.
* Deliver statistical conclusions to enhance the app's overall user experience.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## Key Insights Found
* **Top Cuisine:** American, Japanese, and Italian cuisines dominate total order volumes.
* **Peak Times:** Weekends account for the vast majority of orders, straining delivery networks.
* **Operational Bottleneck:** Delivery times increase significantly during weekend dinner rushes.

## Actionable Recommendations
1. **Dynamic Driver Allocation:** Increase driver density in high-demand sectors during weekend dinner hours.
2. **Targeted Marketing:** Run promotional campaigns for underperforming cuisines during weekdays.
3. **Rating Incentives:** Offer reward points to customers who leave feedback to maximize rating data availability.
